Native gameplay support
Keep this work on feature/native-gameplay in the PRIVATE platform repository.
The game remains in its private feature/3ds-port integration. Neither main branch
nor public GBA distribution changes. No game assets or binary are committed here.

Add a plain fixed-width runtime boundary: framebuffer presentation, input,
RomFS payload loading, SD logging and native PCM output. Prefer NDSP; when DSP
firmware is unavailable, use two acquired CSND channels and a primed stereo ring.
The private game frame pump now supplies701 stereo samples per frame. Native
Azahar testing confirms CSND starts with nonzero stereo PCM, not just a ready flag.
The current tests do not claim a listening or long-duration drift qualification.

Resident data relocation validates magic/version, region and exact file sizes,
counts and relocation sites. It supports the unaligned pointers in game scripts.
Only symbols in the bundled section become resident offsets; BSS/native audio
state and absolute symbols stay out of that namespace. Targeted host/SDK tests
cover malformed inputs and a real assembled mixed-section regression fixture.

Decode256-colour text backgrounds with scrolling, map sizes, flip bits, window
clipping and saturated colour effects. Host tests inspect153600 pixels plus
specific blend/brightness/flip/window cases. Preserve existing input/DMA/colour
contracts. CI cross-compiles the actual runtime in addition to its diagnostic.
The full private integration clean-builds and runs actual FireRed gameplay;
qualification remains in progress. This platform repository alone is no game.

Implement a plain-C native-game boundary, aligned virtual GBA register/video/

decoder, CPU copy/fill operations and immediate/VBlank/HBlank repeating DMA.
Reject unsupported FIFO/audio requests rather than silently claiming support.
Use640-bank FireRed and512-bank imported Emerald selectors with 32-bit FireRed

Retain original video decode helpers and expose their real CtrVideoMemory layout.

Host tests cover input, memory views, copies/fills, delayed/repeating DMA,
all 2048 bank/ID combinations and all 65536 packed map blocks. The target builds

has no game/save loader. An independent private integration links actual FireRed
RNG/tasks and guards original map/sprite/save ABI; no game source/assets are
copied into this public fork. Whole-game startup, resources, scripting, audio,
save storage, menus and Kanto voxel models are not complete.

engine as a FireRed game. Preserve the stable game and public BPS patcher.
